work control center

cortex

One folder you open Copilot CLI from to orchestrate all your projects. Triage a request, route it to the right repo, dispatch a specialist, capture loose ideas — without ever touching your global config.

Install

irm https://raw.githubusercontent.com/aasis21/cortex-hq/main/install.ps1 | iex

Scaffolds an HQ under ~ and registers a launch command. Defaults to cortex, or pick another so several focused HQs coexist on one machine:

cortexneuronnexusaxonhubhelmatlas+ custom

Cross-platform: python install.py

What you get

  • registry.json — single source of truth for your projects
  • orchestrator — triages a request and routes it to the right repo
  • specialist template — one focused agent per repo
  • your folder — add prompts, skills, scripts as you grow
  • self-contained — never writes to ~/.copilot; MCP loads locally
