# anya

- **Path:** `C:\Users\akash\Anya`  •  **Repo:** aasis21/anya  •  **Status:** active
- Chromium MV3 sidebar extension wrapping `@github/copilot-sdk` via a Node Native
  Messaging bridge; spawns playwright-cli for in-tab browser automation. No cloud.

## Commands
- Extension: `cd extension; npm install; npm run build`  (type-check: `npx tsc --noEmit`)
- Bridge: `cd bridge; npm install; npx tsc -p .`  (type-check: `npx tsc --noEmit`)
- Register host: `pwsh ./install.ps1`
